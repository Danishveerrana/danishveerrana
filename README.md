## About Me

I'm a Class 12 student (PCM + Computer Science) who builds things from scratch — mostly self-taught, mostly through late-night projects that started as "let me just try this."

I like turning small ideas into working software: a voice-controlled drawing tool, a music player with a live visualizer, a game with AI and peer-to-peer multiplayer. I care about clean design as much as clean code.
